# 工時計算

把打卡系統匯出的 Excel 拖進網頁，自動算出每人工時，填入月薪／時薪後一鍵匯出 Excel。
資料只在使用者自己的電腦處理，不會上傳。

## 使用
1. 打開 `index.html`（雙擊即可，不用網路；或用 GitHub Pages 網址）。
2. 把打卡 Excel 拖進首頁。
3. 在表格填每個人的「月薪」或「時薪」金額（會記在這台電腦，下個月不用重打）。
4. 按「匯出 Excel」。匯出檔內的時數與薪資是公式，在 Excel 裡改明細會自動重算。

## 計算規則
- 上班就近進位到整點／半點（08:58→09:00，09:12→09:00，09:22→09:30）。
- 下班往前扣到整點／半點（16:37→16:30，16:52→16:30）。
- 例外：下班 :20～:29 視為 :20、:50～:59 視為 :50（小時尾數 .3、.8）。
- 休息不用打卡：滿 4 小時扣 0.5，滿 8 小時扣 1。
- 同一人同一天的上下班合併；只有單邊打卡的標紅，可在明細補時間。
- 規則集中在 `src/core.js`，要調整只改那一個檔案。

## 上架 GitHub Pages
1. 建立新 repository，上傳本資料夾所有檔案（不用上傳 `node_modules`）。
2. Settings → Pages → Source 選 `main` 分支、`/ (root)` → Save。
3. 幾分鐘後用 `https://<帳號>.github.io/<repo 名稱>/` 開啟。

## 修改後重新打包
```
npm install
node build.js     # 產生 index.html（含程式庫，單檔離線可用）
```
